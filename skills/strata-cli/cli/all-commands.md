# Every command, in one line each

The whole surface at a glance — what each command is for, and where its detail lives.

Part of the CLI reference — the index, and every other part, is in [commands.md](../commands.md).

## Every command, in one line each

Commands: **`brief init "<the request, verbatim>" [--into <dir>] [--recipe <name>] [--unattended] [--library <id>] [--force]`** (writes `BRIEF.md`, the one routing artifact every later step reads — the request verbatim, the reconstruction line, the four numbers to declare, constraints with the library from `--library` / `.idm-library` / the `library` preference, and the read list; written once, amended after — [workflow.md](../workflow.md), *Routing*) · **`route "<brief>" [--skill-dir <path>]`** or **`route BRIEF.md`** (the reference files to read for this brief — run first; a brief file routes on its reconstruction line; each matched kind's group opens with its `routes/<kind>.md` page; paths point at the *installed* skill unless `--skill-dir` names the copy you are actually reading) · **`prefs [list] | set <key> <value> [--note "why"] | get <key> | unset <key>`** (answers that repeat across projects — `library`, `aspect`, `fps`, `loudness`, `unattended`, `brand`, `voice`, `music`, `palette`, `fonts`, `renders` — kept in `~/.strata/prefs.json`; check before asking, record after the user answers; `render` falls back to the `library` preference) · **`recipe [list] | save <name> [--from <dir>] [--note "why"] | show <name> | use <name> [--into <dir>] | delete <name>`** (a finished piece's `BRIEF.md`, storyboard, `decisions.md` and `.brand/brand.md` kept by name in `~/.strata/recipes/`; `use` copies them into `<dir>/.recipe/<name>/` and installs the brand document when the project has none — a recipe fills answers, not approvals) · **`review <out.mp4> [--scene scene.json] [--reference ref.mp4] [-o dir]`** (temporal QA of a rendered video: cuts, contact sheet, frames around cuts and settles, freezes, loudness, motion energy, a timecoded report — step 7) · **`deconstruct <video.mp4> [-o tokens.json]`** (a reference clip → measurable tokens: shot lengths, cut rhythm, motion energy per shot, palette, audio onsets — so "premium" is numbers, not an adjective) · `compile` · `validate` · **`versions <scene>`** / **`revert <scene> --to N`** (automatic per-scene history — see step 5) · **`preview <scene> [--at <sec>] [--grid] [--comp <name>] [-o out.png]`** (free local layout wireframe — no cloud) · **`studio [scene.json] [--port 4321] [--no-open]`** (local browser layout designer → writes `*.guide.json`; only with the user's go-ahead — it waits for them to press Save) · **`jet <frames|video> [--key R,G,B] [--method chroma] [--fps N]`** `[--choke N] [--feather N]` (alpha-video overlay — .jet, not .mp4; `--choke` erodes the keyed matte by N px, negative dilates, `--feather` blurs its edge by N px, both default 0) · **`matte <video> [--width N]`** (remove the background from footage **of a PERSON or a character** → .jet — it is a human matting model, so a product/object/logo clip fails with `no subject found`; key those instead) · **`track <video> [--comp WxH | --point x,y]`** (track a surface → corner_pin, or an element → position keyframes) · **`captions <file|url> [-o cues.json] [--srt f]`** (speech-to-text WITH TIMINGS from audio **or video** — caption bars, VO timing, verifying a generated clip said its line; ⚠ segment-level, not per-word) · **`glyphs <font.ttf> "<text>" | <scene.json>`** (does the font cover the copy — before authoring) · **`beats <audio> [--fps N --bands N]`** (onsets + bpm, and the per-frame envelope, each band normalised by its own peak — never hand-time to music; the envelope can drive any `animate` channel directly: [format.md](../format.md), *Audio-driven channels*) · **`upload <file>`** (host a generation input that has no URL — public + permanent) · `inspect <file.idm> [--assets <dir>] [-o doc.json]` (unpack an .idm: every asset + the VASCO doc) · `repack <doc.json> -o out.idm` (re-encode an unpacked .idm — **escape hatch only**, VASCO is baked output so text/asset swaps yes, motion no) · `sketch <plan.json>` (blocking animatic → `generate video --ref-video`) · `generate image|video|fastvideo|avatar|narration|music|voices` · **`edit image <img|url> "<what changes>"`** (the same image with one thing changed instead of a fresh roll — source as `image 0`, the invariants written for me, the source's ratio sent, the drift measured and warned on; one edit off the original — [assets.md](../assets.md)) · `add <block>` · `render --library <id> [--data row.json|rows.json]` (a data object personalizes one render by layer name; an array renders one video per row — the template is uploaded once) · `snapshot --library <id> [--at <sec>] [--data row.json]` (poster-only, fast QA — proof a personalized frame cheaply; **`--at` picks the frame**; the default t=1 s is an empty frame on a piece that builds to a reveal. ⚠ every snapshot uploads the scene and leaves an entry in the user's library, so use the versioned filename you intend to keep rather than a throwaway probe scene) · **every command answers `--help`** with its own usage — check there before guessing a flag · `library list|create <name>` (**create is get-or-create — I ask the user which library before the first render, never pick one myself**) · `init` · `auth login|status` · `schema` · `update` · `uninstall`. Add `--json` for machine-readable output (errors on stderr; nothing reads a TTY non-interactively). Exit codes: 0 ok · 1 compile/schema · 2 missing file · 3 auth · 4 render timeout.
