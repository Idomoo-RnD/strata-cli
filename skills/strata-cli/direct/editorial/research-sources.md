Research snapshot: 2026-08-23 — editing grammar, viewer-attention research, editor interviews,
factual-media standards, platform guidance, documentary ethics and accessibility standards. The
sources support decisions; they are not formulas.

## How to use the evidence

Grammar sources define vocabulary; **empirical studies** explain attention under specific test
conditions, not one style's superiority; **editor interviews** are situated craft, not genre law;
**news and documentary frameworks** set stronger integrity boundaries than fiction or promotion;
**platform research** is provider-published and ad-focused, so verify against current specs;
**accessibility standards** can impose requirements and shape the edit early.

## Maintenance notes

Re-check platform specs, advertising guidance, newsroom standards, accessibility standards and
AI/disclosure policies whenever a request depends on current requirements; prefer the official
current page over a cached PDF. Add a source only if it changes an editing decision or boundary,
and when a new interview contradicts a stylistic default keep both as contextual options rather
than making an absolute rule.
