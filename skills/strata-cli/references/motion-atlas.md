# Motion design atlas — the vocabulary layer

~700 named motion concepts: what each is, when to use it, its key parameter or gotcha. **A lookup,
not a read-by-default file** — reach for it for a name, for options you would not have thought of,
to critique motion, or to translate a brief's adjectives into decisions. Naming the concepts is the
point: "stagger the cards on a ramp, land the hero on the downbeat, exit on a mask wipe" is
reviewable; "make it feel nice" is not.

---

## How this sits next to the rest of the skill

This atlas owns **names and taxonomy** — the long tail of what exists and what it is called.
[motion-design.md](motion-design.md) owns **execution and numbers** — the same ideas as real VASCO
keys, measured on this engine.

⛔ **Where both give a number for the same thing, `motion-design.md` wins.** Its figures were
measured on this engine; the atlas quotes general-industry values. Every such collision has already
been replaced by a link — a bare number here that contradicts one of ours is a bug in this file, not
a choice. Two rules from elsewhere override anything here, always: **a brand document beats every
style and token suggestion** ([brand.md](brand.md)), and **measured engine facts beat craft advice**
— the pinhole camera and bottom-anchored text in [format.md](format.md), the no-cuts rule for `.jet`
overlays in [video-generation.md](video-generation.md).

## Workflow — brief to spec

Set the six tone sliders (energy, weight, precision, warmth, density, playfulness) and map
adjectives to parameters — [07](motion/07-narrative-sound-emotion.md) §4, then the
emotion-to-motion table in [motion-design.md](motion-design.md). Lock timing and easing —
[01](motion/01-foundations.md). Choreograph focal order, entrance order, depth and camera —
[02](motion/02-choreography-space-camera.md). Choose text behaviour: **one** entrance, **one**
exit, **one** emphasis — [03](motion/03-typography.md). Choose one primary and one secondary
transition — [04](motion/04-transitions.md). Add surface and effect decisions only where they serve
the story — [05](motion/05-shape-effects-texture.md). Apply the UI, data and brand rules —
[06](motion/06-ui-data-brand.md). Check structure, pacing and sound sync —
[07](motion/07-narrative-sound-emotion.md) §1–3. If the brief names a look, find it in
[08](motion/08-styles-index.md) and execute it from [video-styles.md](video-styles.md) if it has a
deep entry. Run the craft QA and anti-pattern scan — [09](motion/09-production-qa.md). Load only
what the task needs; each file is self-contained.

## Reference map

The nine numbered files are named for what they own — foundations, choreography and camera,
typography, transitions, shape/effects/texture, UI/data/brand, narrative/sound/emotion, the styles
index, production QA — and the Workflow above says when each is loaded. SKILL.md, *What to read for
this brief*, routes to them by brief type. Each is self-contained; load only what the task needs.

## Output patterns

Name the concepts. Ideas → 5–10 named concepts grouped by the workflow steps, one bold and one
safe. A critique → the violated concept, what the viewer experiences, and the fix with a parameter.
A spec → element → concept → parameters, plus the transition system and the sound cues. When two
concepts conflict — overshoot versus legibility, density versus focal clarity — **the one that
protects comprehension wins.**
