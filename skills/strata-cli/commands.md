# The CLI — setup, asset generation, and every command

How to check for and install the binary, the commands that create media (image, video,
avatar, narration, music) with the rules that go with each, and the one-line signature of
every other command with its flags and exit codes. Read this before generating any asset, or
when a command's exact flags matter; the prompting craft for each generator lives in its own
file ([video-generation.md](video-generation.md), [music.md](shoot/music.md), [avatar.md](shoot/avatar.md)).
